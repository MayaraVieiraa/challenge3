# worker/evidencia — Evidências e explicações

| Módulo | Função |
|---|---|---|
| `recuperador.py` | Recuperação jurídica híbrida e reranking. |
| `guardas.py` | Guardas de entrada e saída. |
| `explicador.py` | Geração de explicações com LLM. |
| `prompts.py` | Carregamento de prompts versionados e seus hashes. |
| `indices/` | Integração pgvector, validação de vetores e expansão de documentos-pai. |
| `langgraph/` | Implementação multiagente baseada em LangGraph, com seus contratos, ferramentas e CLI. |
| `agentes/` | Protótipo multiagente alternativo, importado do repositório final. |
| `context_window.py`, `observabilidade.py`, `revisao.py`, `stracting.py` | Capacidades de contexto, observabilidade, revisão e extração estruturada. |
